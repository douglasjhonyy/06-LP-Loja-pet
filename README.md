<h1>Sobre o projeto</h1>

A PataFeliz é uma landing page fictícia criada com o objetivo de praticar e consolidar conceitos fundamentais de desenvolvimento web front-end. O projeto simula o site de uma pet shop profissional, com identidade visual própria, seções completas de conteúdo e interatividade em JavaScript.

- Objetivos de aprendizado
- Estruturar uma página completa com HTML semântico
- Criar um sistema de design coeso com variáveis CSS
- Aplicar layouts responsivos com Flexbox e Grid
- Implementar animações e transições com CSS puro
- Adicionar interatividade com JavaScript vanilla (sem frameworks)
 
----------------------------------------------------------------------
<h1>Estrutura da página</h1>

- Seção	Descrição
- Navbar	Navegação fixa com efeito de vidro fosco e link de agendamento
- Hero	Banner principal com título, estatísticas e ilustração animada
- Serviços	Grade de 6 cards com serviços oferecidos e preços
- Produtos	Vitrine de 6 produtos com botão de adicionar ao carrinho
- Diferenciais	Lista de motivos para escolher a loja
- Depoimentos	6 avaliações de clientes reais
- Localização	Endereço, horários e mapa
- CTA	Captura de e-mail com oferta de desconto
- Footer	Links, redes sociais e informações de contato
------------------------------------------------------------------------
  <h1>Tecnologias utilizadas</h1>

- HTML5	—	Estrutura e semântica
- CSS3	—	Estilização, animações e responsividade
- JavaScript	ES6+	Interatividade e manipulação do DOM
- Google Fonts	—	Tipografia (Nunito + Inter)
